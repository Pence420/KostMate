# KostMate Implementation Plan

> Execution: native in the current session, following the user's request to build and delegation of design choices.

**Goal:** Build a working local KostMate marketplace and owner workspace from the provided PDF.

**Architecture:** React consumes FastAPI JSON endpoints through the same origin. SQLite persists state. An SSE version stream refreshes listings after owner changes.

**Tech Stack:** React, TypeScript, Vite, React Router, Lucide, FastAPI, SQLite, pytest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-17-kostmate-design.md`

## Global constraints

- Indonesian product copy, integer rupiah, minimal responsive UI.
- Owner data and mutations require ownership checks.
- Clearly label illustrative listing data and manual payments.
- No external messages or financial transactions are sent.

## Review focus

1. Empty search returns an actionable empty state.
2. Expired sessions prompt login without losing navigation.
3. A second owner cannot modify another owner's records.
4. Room counts reject out-of-range updates.
5. Mobile filters, dialogs and navigation remain operable.
